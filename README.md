# Co-Sign

Server-side Fabric mod: turn a book and quill into a document that many players sign, then seal it into a normal signed book.

## Features

- Turn a book and quill into a shared document.
- Many players add their signatures.
- Seal it into a normal signed book when done.

## Commands

`/cosign` has `sign`, `edit`, `title` and `finish` subcommands.

## Compatibility

Minecraft 1.21.1, Fabric Loader and Fabric API. Runs on the server; players need no client mod.

## Build

```bash
./gradlew build
```

The jar appears in `build/libs/`.
